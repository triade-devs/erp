A — Alertas em destaque + 2 colunas (Recomendado)

Header com identificação → faixa de alertas críticos coloridos (VAD, ASA, emergência) → duas colunas: pré-avaliação | intraoperatório. Leitura rápida, hierarquia clara.

PACIENTE · CIRURGIA · DATA
① Identificação & Alertas
Nome · Idade · ASA · VAD · Alergias · Emergência
② Pré-Avaliação
Doenças + Medicamentos + Sinais Vitais + Exames + Exame Físico
③ Intraoperatório
Técnica + Via Aérea + Ventilação + Acessos + Medicações

B — Fluxo cronológico (linear)

3 seções empilhadas na ordem temporal: alertas → pré → intra. Mais legível mas com risco de ultrapassar 1 página se houver muitas medicações ou doenças positivas.

C — Painel de alertas lateral

Coluna estreita esquerda dedicada a alertas críticos + sinais vitais. Coluna larga direita para o restante das informações. Alertas sempre visíveis, porém layout mais complexo.
