Qual é o propósito principal do Resumo?

Isso vai definir o que incluir e como organizar o documento

A

Resumo para o Centro Cirúrgico

Documento de referência rápida para a equipe cirúrgica antes/durante o procedimento. Prioriza dados críticos: ASA, VAD, alergias, técnica, medicações e sinais vitais.

B

Prontuário Completo Consolidado

Documento de arquivo que reúne tudo das duas fichas em um só lugar — pré-avaliação + intraoperatório — para o prontuário do paciente.

C

Nota de Alta / Relatório Pós-Operatório

Documento voltado para o paciente ou para outros médicos: o que foi feito, como foi a anestesia, intercorrências e observações finais.
